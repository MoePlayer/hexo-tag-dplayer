hexo-tag-dplayer 示例

以下是插件生成的播放器效果演示，等效于在 Hexo 文章中使用 {% dplayer %} 标签。

示例 1 — 基础视频播放

Hexo 写法: {% dplayer "url=https://example.com/video.mp4" "pic=https://example.com/cover.jpg" %}

示例 2 — 带弹幕的视频

Hexo 写法: {% dplayer "url=视频地址" "id=myVideo" "api=https://api.prprpr.me/dplayer/" "loop=yes" "theme=#FADFA3" %}

示例 3 — 指定播放器尺寸

Hexo 写法: {% dplayer "url=视频地址" "width=640px" "height=360px" %}

🔧 配置参考

在 Hexo _config.yml 中的推荐配置:

hexo-tag-dplayer:
  js_path: /assets/js/
  default:
    api: https://api.prprpr.me/dplayer/
    theme: '#FADFA3'
    autoplay: false
